## Overview

Noir Music is an independent open-source Android music player with a customized identity and user interface.

Noir Music delivers a seamless listening experience with streaming, offline downloads, synchronized lyrics, music recognition, and extensive customization options.

> [!IMPORTANT]
> **In-app OTA updates have been permanently removed.** Please update manually using the latest release. Noir Music is completely free and ad-free.

## Features

### What's New

- **Data Saver Mode** — Automatically reduces data usage during playback.
- **Settings Search Index** — Quickly find and navigate to settings options.
- **Redesigned UI** — Cleaner, faster, and more intuitive interface.
- **Import & Sync from Spotify** — Import playlists and keep them synchronized.
- **Listen Together** — Sync music playback in real time.
- **Podcast Support** — Listen to podcasts alongside your music.
- **Local Media Support** — Play music stored directly on your device.
- **Dynamic Island Support** — Enhanced playback notifications on supported devices.

<details>
<summary><b>Streaming & Playback</b></summary>

- **Ad-Free** — Stream without interruptions.
- **Data Saver Mode** — Reduce cellular data consumption.
- **Seamless Playback** — Switch between audio-only and video modes.
- **Background Playback** — Listen while using other apps or with the screen off.
- **Offline Mode** — Download tracks, albums, and playlists.
- **Crossfade** — Smooth transitions between tracks.
- **Canvas Animations** — Visual animations while playing music.

</details>

<details>
<summary><b>Discovery & Music Recognition</b></summary>

- **Music Recognition** — Identify songs playing around you.
- **Smart Recommendations** — Personalized suggestions based on listening history.
- **Comprehensive Browsing** — Explore charts, podcasts, moods, and genres.

</details>

<details>
<summary><b>Lyrics</b></summary>

- **Multiple Lyric Animations** — Choose from various lyric display styles.
- **Word-by-Word Lyrics** — Precise per-word synchronization.
- **Lyrics+** — Improved lyrics provider for better accuracy and coverage.
- **AI Translation** — Translate lyrics into different languages.

</details>

<details>
<summary><b>Integrations</b></summary>

- **Music Sharing via Odesli** — Share songs as Song.link for cross-platform listening.
- **Set as Ringtone** — Directly set songs as your device ringtone.

</details>

<details>
<summary><b>Smart Playback</b></summary>

- **Pause on Mute** — Automatically pause when your device is muted.
- **Resume on Bluetooth** — Resume playback when headphones or earbuds reconnect.

</details>

<details>
<summary><b>Customization</b></summary>

- **UI Density Scale** — Adjust interface spacing.
- **High Refresh Rate Support** — Smoother UI on supported displays.
- **Fluid UI & Animations** — Smooth Material 3 animations.
- **Hide Player Thumbnail** — Keep the player minimal.
- **Crop Album Art** — Adjust album art display.
- **Hide Video Songs** — Filter video content.
- **Hide YouTube Shorts** — Keep Shorts out of music browsing.

</details>

## Installation & Setup

### Android Installation

Download the latest pre-compiled APK from the Noir Music releases page:

https://github.com/bipinsanjeeva/Noir-Music/releases

### Building from Source

Clone the repository:

```bash
git clone https://github.com/bipinsanjeeva/Noir-Music.git
cd Noir-Music
```

Configure the Android SDK using a `local.properties` file.

For detailed development setup instructions, see [SETUP.md](SETUP.md).

### Build Variants

Noir Music provides FOSS and GMS build variants.

#### FOSS

```bash
./gradlew assembleUniversalFossDebug
```

#### GMS

```bash
./gradlew assembleUniversalGmsDebug
```
